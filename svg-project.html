SVG Animation

A Breezy Study Desk

About This Project

This project is based on a simple study desk with a table fan, books, an open notebook, a coffee cup, and a small plant.

The idea is to show how a small desk fan creates movement in everyday objects.

The Study Desk

Animation Techniques

This project uses grouped SVG shapes and named paths for CSS animations.

  • Rotation for the table fan.
  • Movement for the airflow paths.
  • Gentle movement for notebook pages.
  • Opacity changes for coffee steam.
  • Small rotations for plant leaves.
